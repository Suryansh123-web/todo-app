# Franky's SUPER Task Deck

A responsive, cola-powered to-do list built with plain HTML, CSS, and vanilla JavaScript. The interface brings a loud comic-book workshop vibe, with electric blue, red, and star-yellow accents, playful motion, and a confetti burst whenever a mission gets completed.

## Features

- Add, edit, delete, and complete tasks
- Filter between all, in-progress, and smashed missions
- Live task totals and remaining-mission counter
- Tasks and theme preference saved with `localStorage`
- A celebratory confetti and party popper effect on completion
- Light and dark themes
- Responsive layout, keyboard focus styles, skip link, and screen-reader announcements
- Reduced-motion support
- No frameworks or build step

## Run locally

Open `index.html` in your browser, or use the Live Server extension in VS Code.

Tasks stay in this browser's local storage. Clearing browser data or switching devices or browsers may remove or hide them. Google Fonts load over the internet; system fonts are used as a fallback.
